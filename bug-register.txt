     applicationId:
       POST /api/stripe/accept-no-charge   {applicationId}
       POST /api/stripe/charge-balance     {applicationId}
       POST /api/stripe/refund-deposit     {applicationId, reason?}
       POST /api/stripe/create-checkout-session {pipelineId,applicationData,returnUrl}
     Evidence: bogus UUID -> 404 {"error":"Application not found"} with NO 401.
     Client sends no Authorization header.
  C2 [MEDIUM] Unauth + unrate-limited AI proxy (aply-server.onrender.com):
       POST /ai/enrich-company   -> 200
       POST /ai/evaluate-lane-fit-> 400/200
     3 rapid calls all 200. Prompt injection resisted.
  C3 [LOW] Firebase Auth user enumeration (project mrkt-2efde):
       accounts:createAuthUri -> registered boolean
       accounts:sendOobCode   -> EMAIL_NOT_FOUND
       accounts:signInWithPassword -> EMAIL_NOT_FOUND vs INVALID_PASSWORD
  C4 [LOW] Public data/validity endpoints:
       GET /api/company-categories (static list, 200)
       GET /api/invites/:token            -> {valid:false,status:not_found}
       GET /api/collab/invites/:token     -> {valid:false,status:not_found}
